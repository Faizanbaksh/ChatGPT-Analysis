# ChatGPT-Analysis
ChatGPT Reviews Analysis
📌 Project Overview
This project analyzes 2000+ ChatGPT user reviews from Play Store using Python. The goal is to understand user sentiment, common praises and complaints.

📊 Dataset
File: chatgpt_reviews.xlsx
Columns: Review Text, Ratings, Date, Review_length
Size: 1000+ reviews
🛠️ Tools Used
Python, Pandas, Matplotlib, Seaborn
TextBlob for Sentiment Polarity & Subjectivity
WordCloud for text visualization
📈 Key Visualizations
Rating Distribution - Most users gave 5-star
Sentiment Analysis - 74% Positive, 26% Negative
WordCloud - Positive words: love, helpful, great | Negative: slow, bug
Review Length vs Rating
Trend over Time
💡 Insights
Users love ChatGPT for coding help and content writing
Major complaints: App slow, paid limit, bugs
Suggestion: Improve speed and free usage limit
🔗 How to Run
Open Copy of chatgpt_reviews_analysis.ipynb in Google Colab and run all cells.
